# `@onlyweb/frontend`

This package provides the core building blocks for creating interactive custom elements (web components) within the OnlyWeb Framework. It focuses on simplifying component creation, state management through attributes, and lifecycle handling.

## Table of Contents (JSR Docs)

> [!WARNING]
> JSR won't generate documentation links until OWF has a full, stable release.

*   **Custom Elements**
    *   `element/element.ts` - The base class (`OWFElement`) for creating OnlyWeb custom elements.
    *   `element/register.ts` - Function to define and register custom elements with the browser.
    *   `element/html.ts` - A tagged template literal for safely creating HTML content within elements.
    *   `element/types.ts` - Core type definitions used by the element system.
